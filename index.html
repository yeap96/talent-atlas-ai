Talent Atlas AI Privacy Policy

Last updated: August 12, 2026

Overview

Talent Atlas AI is a Chrome extension for candidate sourcing. It helps recruiters create search strategies, review candidate profiles found through Google, and optionally verify candidate location information on LinkedIn.

Data processed by the extension

Talent Atlas AI may process the following information solely to provide its candidate-sourcing functionality:

  • Candidate information displayed on Google search-result pages, such as profile names, titles, snippets, locations, and LinkedIn profile links.
  • If the user enables LinkedIn location verification, limited information displayed on opened LinkedIn profile pages, including profile location and headline.
  • The vacancy/candidate description, preferred location, and allowed country entered by the user.
  • Local product state such as Contacted/Skip history, search progress, and cached search plans.

How data is used

Website content is used only to identify, organize, filter, and verify candidate profiles for the sourcing workflow requested by the user. Candidate page data is stored locally in the user's Chrome profile in the Free Beta.

AI search planning

The vacancy description, preferred location, and allowed country are transmitted over HTTPS to the Talent Atlas AI planner hosted on Supabase. The planner uses OpenAI to generate a structured search strategy. Candidate Google or LinkedIn page content is not sent to OpenAI by the Free Beta for search planning.

Data sharing

Talent Atlas AI does not sell user data. Data is shared only with service providers needed to provide the requested AI search-planning feature, currently Supabase and OpenAI, and only for that purpose.

LinkedIn access

LinkedIn location verification is optional. When disabled, Talent Atlas AI does not open LinkedIn profiles for automatic location verification. Users may still choose to open a LinkedIn profile manually.

Retention

Contacted/Skip history and sourcing state in the Free Beta are stored locally in the user's Chrome profile and may be removed by clearing extension data or uninstalling the extension.

Security

Network requests made by Talent Atlas AI use HTTPS. OpenAI API credentials are stored server-side and are not included in the public Chrome extension.

Limited Use

Talent Atlas AI's use of information received from Chrome APIs and website content complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide or improve the extension's single candidate-sourcing purpose and is not used for personalized advertising, creditworthiness, or unrelated purposes.
