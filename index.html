Talent Atlas AI Privacy Policy Last updated: September 2, 2026 Overview Talent Atlas AI is a Chrome extension for candidate sourcing. It helps recruiters create search strategies, review candidate profiles found through Google, and optionally verify candidate location information on LinkedIn. Data processed by the extension Talent Atlas AI may process the following information solely to provide its candidate-sourcing functionality: * Candidate information displayed on Google search-result pages, such as profile names, titles, snippets, locations, and LinkedIn profile links. * If the user enables LinkedIn location verification, limited information displayed on opened LinkedIn profile pages, including profile location and headline. * The vacancy/candidate description, preferred location, and allowed country entered by the user. * Local product state such as Contacted/Skip history, search progress, and cached search plans. * If the user opts in to anonymous product analytics, an anonymous installation identifier and product-use events such as extension opens, vacancy creation, searches, candidate opens, Contacted/Skip actions, and Pro interest. How data is used Website content is used only to identify, organize, filter, and verify candidate profiles for the sourcing workflow requested by the user. Candidate page data is stored locally in the user's Chrome profile in the Free Beta. AI search planning The vacancy description, preferred location, and allowed country are transmitted over HTTPS to the Talent Atlas AI planner hosted on Supabase. The planner uses OpenAI to generate a structured search strategy. Candidate Google or LinkedIn page content is not sent to OpenAI by the Free Beta for search planning. Anonymous product analytics Anonymous product analytics are optional and disabled until the user opts in. When enabled, Talent Atlas AI sends product-use events through a Talent Atlas Supabase Edge Function to PostHog US Cloud. Analytics use a random installation identifier and may include the extension version, search number, result count, search duration, selected country, strict-location setting, LinkedIn verification count, and the part of the extension where an action occurred. Analytics do not include candidate names, candidate LinkedIn URLs, vacancy descriptions, Google search queries, Google Sheet content, email addresses, or other candidate page content. PostHog person-profile processing is disabled for these events. Data sharing Talent Atlas AI does not sell user data. Data is shared only with service providers needed to provide or improve the extension's candidate-sourcing functionality. Supabase and OpenAI are used for AI search planning. If anonymous analytics are enabled, Supabase and PostHog are used to deliver and analyze anonymous product-use events. LinkedIn access LinkedIn location verification is optional. When disabled, Talent Atlas AI does not open LinkedIn profiles for automatic location verification. Users may still choose to open a LinkedIn profile manually. Retention Contacted/Skip history and sourcing state in the Free Beta are stored locally in the user's Chrome profile and may be removed by clearing extension data or uninstalling the extension. Anonymous analytics, when enabled, are retained by PostHog according to the analytics service configuration and cannot be tied by Talent Atlas to a named individual because the extension does not send identity information. Security Network requests made by Talent Atlas AI use HTTPS. OpenAI API credentials are stored server-side and are not included in the public Chrome extension. Limited Use Talent Atlas AI's use of information received from Chrome APIs and website content complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide or improve the extension's single candidate-sourcing purpose and is not used for personalized advertising, creditworthiness, or unrelated purposes.
